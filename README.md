# Kubernetes Production Monitoring & DevSecOps Project

## Project Overview
This project demonstrates a DevOps workflow for building, securing, deploying, and monitoring a containerized application.

## Architecture
GitHub → Jenkins → SonarQube → Trivy → Docker → Kubernetes → Helm → Argo CD → Prometheus → Grafana → Alertmanager → Loki

## Tools and Technologies
- **Version Control:** Git, GitHub
- **CI/CD:** Jenkins
- **Code Quality:** SonarQube
- **Security Scanning:** Trivy
- **Containerization:** Docker
- **Orchestration:** Kubernetes
- **Deployment:** Helm, Argo CD
- **Monitoring:** Prometheus, Grafana, Alertmanager
- **Logging:** Loki
- **Cloud Platform:** Microsoft Azure

## Project Goals
- Automate application build and deployment.
- Scan code, dependencies, and container images for security issues.
- Deploy an application to Kubernetes.
- Monitor application health and performance.
- Configure alerts and centralized logging.
- Document troubleshooting steps and operational procedures.
